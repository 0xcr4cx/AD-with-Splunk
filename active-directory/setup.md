## Active Directory Setup

Configured a Windows Server 2022 machine as an **Active Directory Domain Controller** and created the lab domain environment.

The setup included:

* Installing Active Directory Domain Services (AD DS)
* Configuring the domain
* Setting up DNS
* Creating users and security groups
* Joining the Windows client to the domain
