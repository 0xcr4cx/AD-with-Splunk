## Group Policy Configuration

Configured **Group Policy Objects (GPOs)** to apply security and auditing settings across the domain.

The policies were used to improve visibility into user activity and generate useful Windows security events for the Splunk monitoring environment.

Key configurations included:

* Password and account policies
* Account lockout settings
* Windows auditing
* PowerShell logging
* Security-related event logging
